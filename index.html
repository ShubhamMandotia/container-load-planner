How to fill nested cartons
  1. Give each nested carton a Nest Group code. Any text works; the SKU root is easiest, e.g. NAF2580 for NAF2580L + NAF2580S.
  2. Write one row per SKU inside the carton, all with the same code. Different cartons need different codes, even if their sizes match.
  3. Case Pack is how many units of that SKU go in one nested carton (A ×2, B ×1, C ×1 → 2, 1, 1).
  4. Units is the total of that SKU shipping. Cartons = Units ÷ Case Pack. Or skip Units and put the number of cartons in Cartons.
  5. Carton size and weight are only needed on the first row of the group.
  • Cartons = Units ÷ Case Pack, rounded up. Leave Units blank to give Cartons directly.
  • Side Up says which side must stand vertical: L, W or H (Y also means H). Blank or N lets the carton go on any side.
